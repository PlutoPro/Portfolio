Introducing gurl: Rebuilding curl in Go

November 19, 2026

Every developer and sysadmin has typed curl more times than they can count. It is one of those tools that quietly sits underneath everything: testing APIs, downloading files, debugging servers. I wanted to understand what actually happens behind that command, so I decided to build my own version of it from scratch. The result is gurl, a Go rendition of curl.

Why rebuild curl?

Using a tool and understanding a tool are two very different things. Coming from an infrastructure and networking background, I know what HTTP looks like on the wire, but writing the client myself forces me to deal with every detail: building requests, handling headers, reading responses, following redirects, and making sense of errors. It is the kind of project that turns knowledge into working code.

Why Go?

Go is a natural fit for networking tools. Its standard library has excellent support for network programming, it compiles to a single static binary that runs anywhere, and its simple syntax keeps the focus on the problem instead of the language. A command-line tool like gurl benefits from all three.

Where it stands today

The first milestone is complete: gurl can make HTTP requests. HTTP is the protocol most people reach for curl to use, so it made sense to build that foundation first and get it right before expanding outward.

One place where gurl intentionally differs from curl is its command structure. Instead of passing a URL and a pile of flags, you tell gurl the protocol first, then the command, then the target:

gurl <protocol> <command> <target>

$ gurl http get example.com

Reading left to right, the command says exactly what it does: use HTTP, send a GET request, to example.com. Grouping commands under each protocol also gives gurl a clean way to grow, since every new protocol gets its own set of commands as it is added.

What's next

The long-term goal is for gurl to be a one-for-one match with curl. That means working through the rest of curl's options and protocols piece by piece until gurl can stand in for the original. I will be writing about each milestone here as it lands, including the parts that turned out harder than expected.

If you want to follow along or look at the code, the project is available on GitHub.
